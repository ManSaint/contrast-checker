This is a static design mockup, not the production build. Dark mode is the primary (and only) mode shown here per the product's dark-mode-first requirement. Fonts render via system stacks (ui-monospace / ui-sans-serif) for offline preview; the implementation should use JetBrains Mono for the mono role and Inter for the sans role, per the design spec. Interactive states (hover, focus-visible, invalid) are wired with real CSS — tab through the inputs and swatch buttons to see the focus ring.
